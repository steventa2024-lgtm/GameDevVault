# GameDev Vault

GameDev Vault gives game teams a private workspace to share builds and art, review asset revisions, and keep design decisions close to the files they describe.

[Open GameDev Vault](https://gamedev-vault-staging-qa-zeropulse.vercel.app) · [Desktop installation and checksums](https://gamedev-vault-staging-qa-zeropulse.vercel.app/install)

## What you can do

- **Collaborate in private workspaces.** Invite teammates, talk in channels, and start voice or video calls with screen sharing.
- **Keep every asset revision in one place.** Upload individual files or project archives and reopen previous versions from the Vault.
- **Inspect assets before downloading.** Orbit supported 3D models, play embedded animation clips, and preview concept art, audio, and effects recordings.
- **Review exact revisions.** Compare previews and leave timed feedback or pins on 3D assets.
- **Connect your project notes.** Link shared notes to each other and to stored assets, then explore those connections in the Brain graph.

## Asset previews

The web and desktop apps use the same Vault. Drop originals onto the Channel Vault or use **Upload files**.

| Asset | Preview |
| --- | --- |
| GLB, self-contained glTF, FBX, and OBJ | Interactive geometry. Supported models can also play embedded animation clips. |
| BVH motion capture | Play and scrub motion on the file’s own skeleton. |
| Images, audio, and video | Preview supported browser formats, including PNG, GIF, WAV, MP3, MP4, and WebM. |
| Animated GIF, APNG, and WebP | Inspect individual frames and play the animation in browsers with a compatible image decoder. |
| Roblox models and places | Inspect supported part layouts, schematic poses, and effect metadata. Use an exported GLB for original meshes or a Studio recording for rendered effects. |
| Lua and Luau | Read, highlight, and copy script source in the inspector. |
| Unity `.anim`, shaders, scenes, and configs | Read supported source files up to 1 MiB. Link an engine export or recording for rendered playback. |
| Blender, PSD, and project archives | View metadata, download the original, or link a companion preview. |
